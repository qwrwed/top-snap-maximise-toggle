# Top Snap / Maximise Toggle

KWin script: Meta+Up snaps the active window to the top half, and a second press maximises it.

Install (the live copy is read from `~/.local/share/kwin/scripts/top-snap-maximise-toggle`):

```bash
mkdir -p ~/.local/share/kwin/scripts/top-snap-maximise-toggle
cp -r metadata.json contents ~/.local/share/kwin/scripts/top-snap-maximise-toggle/
```

Then enable it under System Settings → Window Management → KWin Scripts, or log out and in.
